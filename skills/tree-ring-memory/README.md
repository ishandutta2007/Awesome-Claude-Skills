# Tree Ring Memory Skill

Lifecycle-aware memory guidance for AI agents working in long-running projects.

## Usage

Use when a Claude workflow needs to decide what to remember, recall, consolidate,
redact, forget, or source-link across project work.

This skill points agents toward Tree Ring Memory's local-first CLI model: concise
durable memories, project-scoped recall, evidence-backed promotion, and explicit
forgetting instead of unbounded transcript retention.
